# Layout strategy

## Hierarchy

- Decide the reading order before the styling: what users must see first,
  second, third.
- Three or four clear levels: page title, section headings, body, supporting
  text. Size and weight create hierarchy; colour supports it.
- One primary action per screen; place it where the flow ends (end of a form,
  top right of a list, bottom of a mobile screen).
- Group related things by proximity and alignment; separate unrelated things
  with space before reaching for borders or cards.

## Composition

- A clear grid; edges line up across sections.
- Spacing from the project's spacing scale — no one-off gaps.
- Content widths: reading text about 50–80 characters per line; forms not
  stretched across wide screens; data screens may use the full width
  deliberately.
- Balance: one strong element per screen (the key data, the main action, or
  the product's signature idea where it helps), everything around it quiet.
- Avoid the "everything in identical cards" layout; use cards only for
  genuinely separate, comparable items.

## Screen archetypes

| Screen | Layout priorities |
|---|---|
| Landing / marketing | one message above the fold, proof, a clear call to action, sections in a story order |
| List / index | search and filters, the list itself, bulk actions only when selected, pagination or infinite load |
| Detail | the record's identity and status at the top, primary actions near it, facets in sections or tabs |
| Form | one column, logical groups, labels above fields, the submit action at the end |
| Dashboard | the few numbers that matter most where the eye lands, trends next, detail on demand |
| Conversation (AI) | the conversation as the centre, input always reachable, context (sources, tools) beside or within messages |
| Settings | grouped by task, save behaviour obvious (auto-save with confirmation, or an explicit save) |

## Density

- Daily-use, information-heavy screens (enterprise, admin, operations):
  compact rows, tabular figures, strong alignment, keyboard shortcuts for
  frequent actions — but never text below the readable floor.
- Occasional-use, consumer or marketing screens: more space, larger type,
  guided flows.
